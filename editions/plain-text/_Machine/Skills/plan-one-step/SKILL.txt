---
name: plan-one-step
description: Propose a small next step for an agreed project while preserving held ideas and unresolved decisions.
---

Use when selected by the participant and a current planning request fits. Follow the kit’s entry, project boundaries, and approved PM settings. This original procedure needs no external tools; without file access, ask for the specific permitted current project note.

Read where the project has reached. A commitment, a possibility, and an unknown may be sitting in the same paragraph. Keep them distinguishable.

The person asked for a next step. Offer one that follows from the actual work, with its reason; if they want the wider map, unfold it. Ask only for information that would change the step. Do not assign a deadline to make the plan look complete, or treat every appealing idea as a task.

If the person says the plan no longer fits, return to what they are trying to do. The skill serves that work; the person need not defend a change of mind against a procedure you brought.

Within authority, record an accepted task only on the One List, linking its project/source. Keep unaccepted ideas held in their project. Reopen the changed note if file tools exist; otherwise provide exact text to save and say saving is unverified.

Success: the next step is useful and authorized, while held ideas remain uncommitted. Record this skill as tested only after its behavior has actually been checked on permitted work. No workshop exercise is required.
