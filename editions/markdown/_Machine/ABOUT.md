# The instructions are here, if you want to look

These are instructions and notes the guide can maintain within permission. They are ordinary text. They are not evidence that an agent, connection, skill, or scheduled job exists in the app.

Read HELPERS.md when the person asks for more help. The default guide can do one job at a time; no multi-agent system is needed to use this folder. Read SESSION-TENDING.md only if continuity work is requested.

Keep approved handoffs scoped to their projects. Do not build a global archive of everything the participant ever said. If an instruction changes, update the file that governs it and check the links. Two different versions of “always do this” will not become clearer through repetition.

For practical setup failures, read [settings help](SETTINGS-AND-STUCK.md). For more rooms, skills, or agents, read [Make it yours](MAKE-IT-YOURS.md). Bring these in when useful; they are not another reading assignment for the participant.
