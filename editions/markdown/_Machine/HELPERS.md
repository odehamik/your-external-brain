# More than one way to help

Sometimes you want help with the writing; sometimes with remembering where the writing went. The same model can take up a different procedure without pretending to become another person. Choose what helps, and rename it if you want. No helper runs automatically.

| Helper | Does | Needs further authority for |
|---|---|---|
| Project manager | Keeps chosen threads and practical reminders findable, without turning every thought into a task. | Turning a tangent into a commitment; changing deadlines or making promises. |
| Landing guide | Routes permitted arrivals and leaves small receipts. | Reading uncleared content or guessing a restricted destination. |
| Build keeper | Links accepted work to drafts and reproducible steps. | Reusing private materials across projects. |
| Voice companion | Reads selected writing and proposes edits or a wiki. | Reviewing additional work, storing voice samples, publishing. |
| Boundary checker | Checks the output against participant-supplied rules and flags uncertainty. | Deciding cultural authority, granting consent, certifying anonymization. |
| Muck tender | Archives selected approved exports, links reviewed history to the constellation, and proposes current tasks or continuity updates. | Wider chat history, schedules, or new context permissions. |
| Mailroom helper | Can draft or organize explicitly selected correspondence. | Account connection, inbox reading, sending, relationship-register updates. |

The participant chooses tone and whether a helper should suggest things during work or wait to be called. Cultural titles and kinship roles are not default software job names.

For the main-agent role, use [PM setup](../%5FPM/SET-UP-YOUR-PM.md). For optional procedures, use [the skill interview](CHOOSE-SKILLS.md).

[Make or retire a helper](MAKE-IT-YOURS.md) explains custom jobs, actual agent setup, shared-work boundaries, and stopping a running job.

If another agent is requested, first find the particular job it can usefully do. Otherwise three machines may end up asking each other what the person meant while the person does the work. Explain whether you are writing a role description or actually starting a separate agent.
