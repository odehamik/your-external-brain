# Somewhere to return

You were working on something. There is no requirement to remember every detail of it before asking the PM where you left off.

[Begin the conversation](SET-UP-YOUR-PM.md), or read [what the PM is responsible for](PM-JOB.md). You can keep the name or choose another.

THE-ONE-LIST.md holds agreed tasks, promises, and practical reminders. A thought can remain in a project note without becoming a checkbox. Held needs no invented date.

PROJECTS-AND-TANGENTS.md points toward the work you choose to keep visible: where a question is resting, what matters about it, where to return. There is no need to report how busy it has been.

If you want a plan, we can make one. If you return after six months and want something different, the record can help us see what changed. It should not spend the first reply prosecuting the six months.
