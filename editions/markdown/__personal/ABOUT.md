# Human-only marker

This practice folder contains no personal material. The guide is instructed not to inspect this room, including its filenames and metadata.

A folder name is not a technical access barrier. Keep genuinely private material outside the AI workspace and any shared copy. A human can read this marker and ask for help arranging access controls without providing the private contents.

Do not put journals, internal political discussions, or personal struggles here merely because the folder says personal. No machine-generated summary should carry such material into context, projects, publications, task lists, or a workshop example.
